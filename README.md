# 🏗️ Inverloch Builders & Bass Coast Builders - High-End Luxury Construction Website

![Website Showcase Grid](https://raw.githubusercontent.com/username/repository/main/assets/website_showcase_mockup.jpg)

A high-performance, responsive, luxury architectural construction & renovation website built for **Inverloch Builders** and **Bass Coast Builders**. Designed with an editorial aesthetic, crystal-clear high-contrast imagery, 11 targeted suburb landing pages, client video testimonial lightboxes, and zero-dependency vanilla web technology.

---

## 🌟 Key Highlights & Features

- **Option 1A Luxury Architectural Homepage:** Dark editorial aesthetic, gold glassmorphism badge, 4-column horizontal service icon strip, featured project cards, and split CTA sections.
- **Option 1B 11 Suburb Location Landing Pages:** Targeted landing pages for Bass Coast suburbs (*Inverloch, Wonthaggi, Cape Paterson, Venus Bay, Phillip Island, Cowes, San Remo, Kilcunda, Leongatha, Korumburra, Tarwin Lower*) designed to deliver full homepage impact while retaining existing URL structures and Google SEO rankings.
- **Option 1C Bass Coast Builders Duplicated Site:** Secondary brand deployment with Ocean Navy theme switching (`data-theme="bass-coast"`), customized logo branding, and unique localized SEO metadata to prevent duplicate content flags.
- **Dedicated Multi-Page Subpages:** 
  - `about.html` — Company story, 15+ years experience, Master Builders accreditation, and core pillars.
  - `services.html` — Detailed breakdowns for Custom Homes, Renovations, Extensions, and Project Management.
  - `projects.html` — High-resolution residential project portfolio gallery.
  - `locations.html` — Interactive directory for all 11 suburb landing pages.
  - `testimonials.html` — Video testimonial hub and 5-star homeowner reviews grid.
  - `contact.html` — Interactive Discovery Call booking form and builder contact lines.
- **Interactive Lightboxes & Modals:** Built-in modal triggers for "Book a Discovery Call" and YouTube client video testimonial lightbox.
- **SEO & Schema.org Optimization:** JSON-LD `GeneralContractor` and `HomeAndConstructionBusiness` structured data integrated across all subpages.

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, Modern CSS3 (Custom Properties, Flexbox, CSS Grid), Vanilla JavaScript (ES6+).
- **SEO & Microdata:** JSON-LD Structured Data, Open Graph tags, Canonical URLs.
- **Typography:** Cormorant Garamond (Serif Headers) & Plus Jakarta Sans (Sans-serif Body).
- **Performance:** Zero external framework dependencies for ultra-fast loading speed and clean DOM rendering.

## 🚀 How to Run Locally & Deploy

### Local Development
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/inverloch-builders-website.git
   ```
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).

### Deployment
This repository is static-ready and can be deployed instantly to:
- **GitHub Pages:** Enable GitHub Pages in repository settings pointing to the `main` branch root.
- **Vercel / Netlify:** Import the repository root directory with default build settings.
